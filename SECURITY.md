# Security Policy

## Reporting a vulnerability

Please report security problems privately to **kontakt@simeonzickert.de**, not in a public issue.

Include what the problem is, how to reproduce it, and which version or commit you tested. You'll get an answer, usually within a few days.

## Supported versions

Only the latest release is supported. Mitschnitt updates itself, so fixes reach users through a new release rather than backports.

## Scope

Mitschnitt and this repository. A problem that also exists in [anarlog](https://github.com/fastrepl/anarlog), the project Mitschnitt started from, should additionally be reported there.
