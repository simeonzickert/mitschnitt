# Security Policy

Mitschnitt is a private fork of [anarlog](https://github.com/fastrepl/anarlog),
maintained by Simeon Zickert. It is not a published product and has no release
channel, so there is nothing here to report against from the outside.

## Reporting

If you have access to this repository and find a security-relevant problem,
report it directly to **kontakt@simeonzickert.de**. Do not open a public issue.

Please include what the problem is, how to reproduce it, and which commit you
tested against.

## Scope

Only this fork is in scope. A vulnerability that also exists in upstream
anarlog belongs to the upstream project and should be reported through its own
channels, not here.

## Supported versions

Only the current `main` is maintained. There are no backports.
